# Screenshots

Showcase screenshots of the pxls web app. They are not tied to any pull request; PR-only screenshots are attached to the PR itself instead.

Taken from a local build with no Pixoo connected, so the device shows as Offline.

| File | Shows |
| --- | --- |
| `device-dark.jpg` | Device page: connection status, MAC address and brightness |
| `device-settings-dark.jpg` | Timezone and display mode settings |
| `page-editor-dark.jpg` | Page editor: page types, colours and weather |
| `webhook-rules-dark.jpg` | Webhooks with a rule that turns a Radarr download into a notification |
| `event-log-dark.jpg` | Event log: matched rule, default display and the raw payload |
| `tools-timers-light.jpg` | Countdown timer presets (light theme) |
| `tools-scoreboard-light.jpg` | Scoreboard and sound detector tools (light theme) |
| `user-menu-light.jpg` | User menu with the Auto, Light and Dark theme switch |
| `diagnostics-dark.jpg` | Diagnostics: raw commands and value sweep (needs `PXLS_ENABLE_DEBUG=1`) |
| `event-log-phone-dark.jpg` | The same app at phone width, with the bottom tabs |
