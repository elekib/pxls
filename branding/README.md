# pxls branding

Logo assets for pxls, generated as pixel-grid SVGs (PNG exports alongside).

| File | Use |
| --- | --- |
| `pxls-logo.svg` / `.png` | Horizontal logo on a dark tile. Works on light and dark backgrounds. |
| `pxls-icon.svg` / `.png` | Square app icon (512px). |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Web icons (also copied to `frontend/public/`). |
| `social-preview.png` / `.svg` | 1280x640 GitHub social preview. Upload under Settings > General > Social preview. |

Palette: `#0a0f1e` background, `#3fa9ff` `#4f5bff` `#b45cff` `#9be564` `#44c97a` accents, `#ffffff` wordmark.

pxls is an unofficial community project and is not affiliated with Divoom. These marks do not use Divoom or Pixoo branding.
